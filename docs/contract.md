# Six-axis laboratory contract v1

All lengths are metres and all joint angles radians, in a right-handed base frame with z up. Base yaw q0 rotates about +z. At shoulder z=0.15, q1 and q2 rotate about local -y, separated by links 0.30 and 0.25 m along local +x. The wrist is co-located: q3 about local +x, q4 about local -y, q5 about local +x. The TCP is 0.10 m along the final +x. This is an ideal six-rotation-joint spherical-wrist teaching model, not a measured commercial or physical arm.

FK uses Rz(q0) Ry(-q1), advances L1, composes Ry(-q2), advances L2, then Rx(q3) Ry(-q4) Rx(q5), advances L3. Limits in degrees: q0 ±150; q1 -60..120; q2 ±135; q3 ±170; q4 ±120; q5 ±170. Home is [0,80,-90,0,30,0] degrees. Rotation inputs are row-major proper 3×3 matrices, finite, orthonormal and determinant +1 within 1e-6; positions are dense finite xyz within ±2 m. UI roll/pitch/yaw is Rz(yaw) Ry(pitch) Rx(roll), degrees converted at the boundary.

IK subtracts the rotated tool offset to find wrist centre. Both signed radial/yaw and elbow branches are evaluated. Local wrist orientation decomposes as Rx(a) Ry(b) Rx(c), where b=-q4; both nonsingular wrist branches and angle wraps are tested against limits and FK residuals. For |sin(b)| near zero, a representative split of the coupled roll sum is returned and marked wrist singular; this is not all members of the infinite family. Near the base axis, yaw representatives include the requested seed and zero; the solver is not a completeness proof for every singular constrained pose. Position/orientation residuals are returned independently for every candidate.

Collision geometry is upper/fore/tool capsules (radii 0.025,0.022,0.020 m), a 0.035 m wrist sphere and 0.030 m TCP sphere, floor and fixed base box. Adjacent parts that share a joint are excluded from self-collision. Conservative obstacle boxes: at most 12, ordered finite xyz within ±2 m. All joint interpolation is bounded by B=.65(|dq0|+|dq1|)+.35|dq2|+.10(|dq3|+|dq4|); q5 has zero geometric effect for the ideal axial tool/capsule. Midpoint capsule inflation B/(2n), n=ceil(B/.008), conservatively covers each full edge, at most 512 pieces. Self checks use twice the inflation. Global pose checks per planning call ≤30000, RRT total nodes ≤1200, iterations ≤1000, accepted waypoints ≤64. Finite failure means no accepted route was found under these limits, not no route exists.

Timing uses quintic zero-endpoint velocity/acceleration scaling, per-joint speed ≤1 rad/s, acceleration ≤2 rad/s², dt .02.. .1 s (default .05), at most 3001 frames and a 3 MiB serialized report. No torque, gravity compensation, force control, dynamics or real safety certification is claimed. Work and output bounds apply before unbounded growth.

A host reference-runner emulator independently rechecks a loaded path with a separate ≤30000-pose budget (combined lab ceiling 60000; both counts are reported). Its reference interval is fixed at 50 ms, while the separately exported trajectory may use another bounded dt. The emulator starts with no output, loads a checked path only while disarmed, arms only at a known initial feedback pose, starts explicitly, and outputs the sampled joint reference. It drops output and latches a fault on invalid/backward clock, watchdog gap >200 ms, nonfinite/out-of-limit feedback or >.05 rad deviation from its prior setpoint. STOP always removes output. Completion holds the final reference only while the same watchdog remains healthy. Reset clears in-memory state; it does not home or move a physical arm. A fault needs explicit reset/load/arm/start; a later tick cannot revive motion. The ideal tracking demo feeds the previous setpoint as feedback, not measured hardware. No serial, USB, MCU driver, flashing or motor API exists.

Browser, CLI and demos share the same core. UI input edits cancel in-flight work and clear prior result/replay/export. The loopback server exposes a fixed file list with GET/HEAD, Host validation and CSP. JSON report import is not supported; external target/config inputs are strictly bounded and validated. The approved generated cover remains labeled concept art; recorded figures use actual model runs. Physical build, calibration, load ratings, electronics/firmware selection and hardware tests remain pending.
